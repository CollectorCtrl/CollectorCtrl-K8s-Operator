# Maintainers

This project is maintained by the **CollectorCtrl Team** ([connect@collectorctrl.com](mailto:connect@collectorctrl.com)).

Maintainers review and merge pull requests, triage issues, cut releases and handle security reports. Every
change to `main` goes through a pull request with passing checks.

To become a maintainer, contribute consistently for a few months (code, reviews or docs) and ask; existing
maintainers decide together.
